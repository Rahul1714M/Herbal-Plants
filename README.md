# 🌿 Herbal Plants Website

A simple and responsive website built using **HTML5** and **CSS3** to spread awareness about some of India's most popular medicinal plants and their health benefits.

This is my **first front-end web development project**, created to improve my HTML and CSS skills while building something useful and informative.

## 🌱 About the Project

This website introduces some of the most commonly used medicinal plants in India, including:

- 🌿 Neem
- 🌱 Tulsi
- 🌾 Ashwagandha
- 🟡 Turmeric
- 🍃 Brahmi

Each section includes:

- A short introduction
- Health benefits
- Simple and clean design
- Easy navigation

The website also explains why medicinal plants are important for our health and the environment.
